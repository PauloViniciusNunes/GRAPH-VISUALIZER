# Visualizador gráfico 3D -> 2D

Este é um protótipo de visualização de gráficos em tensores, selecionando uma fátia do cubo ao qual deseja visualizar o gráfico.

## 1. Pré-instalação

Antes de tentar rodar o projeto, certifique-se que tenha o Node.js e o npm instalado. Use os comandos:

node -v

e

npm -v

Para checar se ambos os pacotes estejam instalados. Caso não possua nenhum, ambos estão disponíveis no site oficial do Node.js: https://nodejs.org/pt-br

## 2. Clonar Repositório

Use o comando para clonar o repositório:

asdsad

## Baixar Dependências

No diretório onde clonou o repositório, utilize:

cd ./GRAPH-VISUALIZER

e depois

npm install

Para instalar o node_modules e as dependências do projeto.

## Rodando o projeto

Após a instalação dos pacotes npm, você agora pode rodar o projeto. Ainda dentro de ./GRAPH-VISUALIZER, use o comando:

npm run dev

Acesse o link que aparece no terminal para visualizar a página web do projeto e testar as funcionalidades.
